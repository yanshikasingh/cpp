# Character Functions in C++

## Introduction

Character functions are used to **check, classify, and modify individual characters**. In C++, these functions are provided by the `<cctype>` header file.

They are useful when working with characters such as:

* Alphabets: `A-Z`, `a-z`
* Digits: `0-9`
* Spaces and tabs
* Punctuation symbols
* Uppercase and lowercase letters

To use character functions in C++, include:

```cpp
#include <cctype>
```

---

# How Characters Work Internally

A computer does not directly understand characters such as `A`, `a`, or `5`. Characters are internally represented using numeric values according to a character encoding.

For example:

| Character | Numeric Value |
| --------- | ------------: |
| `'A'`     |            65 |
| `'B'`     |            66 |
| `'Z'`     |            90 |
| `'a'`     |            97 |
| `'b'`     |            98 |
| `'z'`     |           122 |
| `'0'`     |            48 |
| `'9'`     |            57 |

One important observation is that many characters are arranged in consecutive ranges.

For example:

```text
A B C D ... Z
65 66 67 ... 90
```

Similarly:

```text
a b c d ... z
97 98 99 ... 122
```

And:

```text
0 1 2 3 ... 9
48 49 50 ... 57
```

Because of these ranges, characters can conceptually be checked using comparisons.

For example:

```cpp
ch >= 'A' && ch <= 'Z'
```

This checks whether `ch` is an uppercase alphabet.

> **Note:** These values are commonly shown using ASCII for understanding. Real C++ character classification functions can also depend on the active locale.

# 1. `isalpha()`

The `isalpha()` function checks whether a character is an alphabet.

## Syntax

```cpp
isalpha(ch)
```

## Returns

* Non-zero value if the character is an alphabet.
* `0` if the character is not an alphabet.

## Example

```cpp
#include <iostream>
#include <cctype>

using namespace std;

int main()
{
    char ch = 'A';

    if (isalpha(ch))
    {
        cout << ch << " is an alphabet.";
    }

    return 0;
}
```

## Conceptual Logic

We can understand `isalpha()` approximately as:

```cpp
(ch >= 'A' && ch <= 'Z') ||
(ch >= 'a' && ch <= 'z')
```

### Examples

```text
isalpha('A') → True
isalpha('z') → True
isalpha('5') → False
isalpha('@') → False
```

# 3. `isalnum()`

The `isalnum()` function checks whether a character is either:

* An alphabet
* A digit

The word **alnum** means **alphabet + numeric**.

## Syntax

```cpp
isalnum(ch)
```

## Conceptual Logic

```cpp
isalpha(ch) || isdigit(ch)
```

## Example

```cpp
#include <iostream>
#include <cctype>

using namespace std;

int main()
{
    char ch = 'A';

    if (isalnum(ch))
    {
        cout << ch << " is alphanumeric.";
    }

    return 0;
}
```

### Examples

```text
isalnum('A') → True
isalnum('a') → True
isalnum('5') → True
isalnum('@') → False
```

# 6. `isspace()`

The `isspace()` function checks whether a character is a whitespace character.

Whitespace characters include:

| Character | Meaning         |
| --------- | --------------- |
| `' '`     | Space           |
| `'\n'`    | New line        |
| `'\t'`    | Tab             |
| `'\r'`    | Carriage return |

## Syntax

```cpp
isspace(ch)
```

## Example

```cpp
#include <iostream>
#include <cctype>

using namespace std;

int main()
{
    char ch;

    cout << "Enter a character: ";
    cin.get(ch);

    if (isspace(ch))
    {
        cout << "It is a whitespace character.";
    }
    else
    {
        cout << "It is not a whitespace character.";
    }

    return 0;
}
```

> **Important:** `cin >> ch` usually skips whitespace. Therefore, use `cin.get(ch)` when you want to test a space, tab, or newline.

# 8. `toupper()`

The `toupper()` function converts a lowercase character into uppercase.

## Syntax

```cpp
toupper(ch)
```

### Examples

```text
'a' → 'A'
'b' → 'B'
'z' → 'Z'
```

## Example

```cpp
#include <iostream>
#include <cctype>

using namespace std;

int main()
{
    char ch = 'a';

    char upper = toupper(ch);

    cout << upper;

    return 0;
}
```

## Conceptual Idea

In the commonly used ASCII representation:

```text
'a' = 97
'A' = 65
```

The difference is:

```text
97 - 65 = 32
```

Therefore, conceptually:

```text
'a' - 32 = 'A'
```

However, in real C++ programs, it is better to use:

```cpp
toupper(ch)
```

instead of manually subtracting `32`.

# How Do Character Functions Actually Work?

The basic process can be understood like this:

```text
        CHARACTER
            │
            ▼
  Internally represented
    by a numeric value
            │
            ▼
  Function checks its
  category or property
            │
            ▼
    TRUE / FALSE
```

For example:

```cpp
isalpha('G')
```

Conceptually, the program checks:

```cpp
('G' >= 'A' && 'G' <= 'Z')
```

Since `'G'` lies between `'A'` and `'Z'`, the result is true.

---

# Conceptual Implementation

To understand the logic behind the library functions, we can create our own versions.

## Custom `isalpha()`

```cpp
bool myIsAlpha(char ch)
{
    return (ch >= 'A' && ch <= 'Z') ||
           (ch >= 'a' && ch <= 'z');
}
```

## Custom `isdigit()`

```cpp
bool myIsDigit(char ch)
{
    return ch >= '0' && ch <= '9';
}
```

## Custom `islower()`

```cpp
bool myIsLower(char ch)
{
    return ch >= 'a' && ch <= 'z';
}
```

## Custom `isupper()`

```cpp
bool myIsUpper(char ch)
{
    return ch >= 'A' && ch <= 'Z';
}
```

## Custom `isalnum()`

```cpp
bool myIsAlnum(char ch)
{
    return myIsAlpha(ch) || myIsDigit(ch);
}
```

These functions help us understand the **basic logic** behind character classification.

# Does the Actual Library Use the Same Code?

Not necessarily.

The actual C++ library implementation may use optimized techniques such as **lookup tables**.

Conceptually, the library may store information like this:

| Character | Properties          |
| --------- | ------------------- |
| `'A'`     | Alphabet, Uppercase |
| `'a'`     | Alphabet, Lowercase |
| `'5'`     | Digit               |
| `' '`     | Whitespace          |
| `'!'`     | Punctuation         |

Then the function can quickly determine the properties of a character.

Conceptually:

```text
Character
    │
    ▼
Lookup its properties
    │
    ▼
Return the required result
```

This can be more efficient than repeatedly checking multiple conditions.

# Complete Example Program

```cpp
#include <iostream>
#include <cctype>

using namespace std;

int main()
{
    char ch;

    cout << "Enter a character: ";
    cin.get(ch);

    cout << "\nCharacter: " << ch << endl;

    if (isalpha(ch))
        cout << "It is an alphabet." << endl;

    if (isdigit(ch))
        cout << "It is a digit." << endl;

    if (isalnum(ch))
        cout << "It is alphanumeric." << endl;

    if (islower(ch))
        cout << "It is lowercase." << endl;

    if (isupper(ch))
        cout << "It is uppercase." << endl;

    if (isspace(ch))
        cout << "It is whitespace." << endl;

    if (ispunct(ch))
        cout << "It is punctuation." << endl;

    cout << "Uppercase version: "
         << static_cast<char>(toupper(ch))
         << endl;

    cout << "Lowercase version: "
         << static_cast<char>(tolower(ch))
         << endl;

    return 0;
}
```

# Important Notes

## 1. Include `<cctype>`

To use character functions in C++:

```cpp
#include <cctype>
```

---

## 2. Character functions work with individual characters

Example:

```cpp
char ch = 'A';
```

Then:

```cpp
isalpha(ch);
```

These functions are designed to work with a **single character**, not directly with an entire string.

---

## 3. Do not compare with `true` unnecessarily

Instead of writing:

```cpp
if (isalpha(ch) == true)
```

prefer:

```cpp
if (isalpha(ch))
```

This is simpler and more readable.

---

## 4. Use library functions instead of manually using ASCII numbers

Avoid:

```cpp
if (ch >= 65 && ch <= 90)
```

Prefer:

```cpp
if (isupper(ch))
```

It is easier to read and safer.

# Final Concept

Character functions work by examining the **properties of a character**.

The basic idea is:

```text
Character
    ↓
Character has an internal value
    ↓
The function checks its category
    ↓
Result is returned
```

For example:

```cpp
isalpha(ch)
```

asks:

> **Is this character an alphabet?**

And:

```cpp
isdigit(ch)
```

asks:

> **Is this character a digit?**

These functions make character handling easier, more readable, and more reliable in C++.
