# How C-Style Strings Work Internally

C-style strings are not a separate special object like `std::string`.

A C-style string is simply a **character array that ends with a null character**:

```cpp
'\0'
```

Most C-style string operations work by reading the array **one character at a time** until they find `'\0'`.

To use common C-style string functions:

```cpp
#include <cstring>
```

---

# First: What is a C-Style String?

```cpp
char name[] = "Hello";
```

Conceptually, this is stored as:

```cpp
char name[6] = {'H', 'e', 'l', 'l', 'o', '\0'};
```

Internally, memory can be understood like this:

```text
Index:    0   1   2   3   4    5
         ┌───┬───┬───┬───┬───┬────┐
Value:   │ H │ e │ l │ l │ o │ \0 │
         └───┴───┴───┴───┴───┴────┘
```

The visible word has 5 characters, but the array has one extra character for `'\0'`.

---

# 1. Character Storage

A C-style string stores characters in consecutive positions of a character array.

Example:

```cpp
char word[] = "CAT";
```

Conceptually:

```text
Index:    0   1   2    3
         ┌───┬───┬───┬────┐
Value:   │ C │ A │ T │ \0 │
         └───┴───┴───┴────┘
```

Each character has its own array position.

This means individual characters can be accessed using indexes:

```cpp
cout << word[0];   // C
cout << word[1];   // A
cout << word[2];   // T
```

### Backend idea

```text
C-STYLE STRING
       ↓
Character Array
       ↓
Characters stored one after another
       ↓
H | e | l | l | o | \0
```

---

# 2. Null Terminator (`'\0'`)

The null terminator tells C-style string functions:

> **The string ends here.**

Example:

```cpp
char name[] = "Hello";
```

Memory:

```text
H → e → l → l → o → \0
                    ↑
                 String ends
```

The null terminator is not usually printed as part of the string.

### Why is it necessary?

An array has storage positions, but a string function needs to know where the meaningful text stops.

For example:

```cpp
cout << name;
```

Conceptually:

```text
Start at index 0
       ↓
'H' → print
'e' → print
'l' → print
'l' → print
'o' → print
'\0' → STOP
```

### Common backend pattern

```text
Read character
      ↓
Is it '\0'?
   │       │
  No      Yes
   │       │
Continue   Stop
```

This idea is used repeatedly in C-style string operations.

# 3. Traversing

**Traversing** means moving through a string one character at a time.

Example:

```cpp
char name[] = "Hello";
```

Conceptually:

```text
Index

0 → 1 → 2 → 3 → 4 → 5
│   │   │   │   │   │
H   e   l   l   o   \0
                    ↓
                   STOP
```

A simple traversal:

```cpp
int i = 0;

while (name[i] != '\0')
{
    cout << name[i];
    i++;
}
```

### What happens internally?

```text
i = 0 → Read 'H'
       ↓
Not '\0'
       ↓
Move to next index

i = 1 → Read 'e'
       ↓
Not '\0'
       ↓
Move to next index

...

i = 5 → Read '\0'
       ↓
STOP
```

### Backend idea

```text
START
  ↓
Read current character
  ↓
Is it '\0'?
  ├── No → Process character → Move forward
  │
  └── Yes → STOP
```

Traversal is the foundation of many operations such as:

- Counting
- Copying
- Concatenation
- Comparison
- Searching
- Modification

# 4. String Operations

C-style strings perform different operations by traversing characters and using `'\0'` to determine where the string ends.

---

## 4.1 Length / Counting

### Concept

Length means counting how many characters exist before `'\0'`.

Example:

```text
H e l l o \0

Length = 5
```

### Function

```cpp
strlen()
```

---

## `strlen()` — What Happens Internally?

Suppose:

```cpp
char name[] = "Hello";
```

Memory:

```text
Index:    0   1   2   3   4    5
         ┌───┬───┬───┬───┬───┬────┐
Value:   │ H │ e │ l │ l │ o │ \0 │
         └───┴───┴───┴───┴───┴────┘
```

When you write:

```cpp
strlen(name);
```

The function conceptually starts from the first character and counts until it finds `'\0'`.

### Conceptual Logic

```cpp
int myStrlen(char str[])
{
    int count = 0;

    while (str[count] != '\0')
    {
        count++;
    }

    return count;
}
```

### Step-by-Step

```text
count = 0

Index 0 → 'H' → not '\0' → count = 1
Index 1 → 'e' → not '\0' → count = 2
Index 2 → 'l' → not '\0' → count = 3
Index 3 → 'l' → not '\0' → count = 4
Index 4 → 'o' → not '\0' → count = 5
Index 5 → '\0' → STOP
```

Result:

```text
5
```

### Backend Idea

```text
STRING
   ↓
Start from first character
   ↓
Is it '\0'?
   ├── No → Count it → Move forward
   │
   └── Yes → Stop
   ↓
Return count
```

---

## 4.2 Copying

### Concept

Copying means taking the characters from one string and placing them into another string.

```text
Source:       Hello
                 │
                 ▼
Destination:  Hello
```

### Function

```cpp
strcpy()
```

---

## `strcpy()` — What Happens Internally?

Suppose:

```cpp
char source[] = "Hello";
char destination[20];
```

Initially:

```text
SOURCE:

┌───┬───┬───┬───┬───┬────┐
│ H │ e │ l │ l │ o │ \0 │
└───┴───┴───┴───┴───┴────┘


DESTINATION:

┌───┬───┬───┬───┬───┬───┬───┬───┐
│ ? │ ? │ ? │ ? │ ? │ ? │ ? │ ? │
└───┴───┴───┴───┴───┴───┴───┴───┘
```

Now:

```cpp
strcpy(destination, source);
```

### What happens?

Characters are copied one by one.

Conceptually:

```cpp
int i = 0;

while (source[i] != '\0')
{
    destination[i] = source[i];
    i++;
}

destination[i] = '\0';
```

### Step-by-Step

```text
source[0] = 'H'
        ↓
destination[0] = 'H'

source[1] = 'e'
        ↓
destination[1] = 'e'

source[2] = 'l'
        ↓
destination[2] = 'l'

...
```

Finally:

```text
DESTINATION:

┌───┬───┬───┬───┬───┬────┐
│ H │ e │ l │ l │ o │ \0 │
└───┴───┴───┴───┴───┴────┘
```

### Very Important

The destination must have enough space.

The resulting string must also end with `'\0'`.

---

## 4.3 Concatenation

### Concept

Concatenation means joining one string to the end of another string.

```text
"Hello " + "World"

        ↓

"Hello World"
```

### Function

```cpp
strcat()
```

---

## `strcat()` — What Happens Internally?

Suppose:

```cpp
char str1[20] = "Hello ";
char str2[] = "World";
```

Conceptually:

```text
str1:

H → e → l → l → o → space → \0


str2:

W → o → r → l → d → \0
```

Now:

```cpp
strcat(str1, str2);
```

### Step 1: Find the end of `str1`

```text
H → not '\0'
e → not '\0'
l → not '\0'
l → not '\0'
o → not '\0'
space → not '\0'
\0 → FOUND!
```

### Step 2: Copy `str2` from that position

```text
Before:

Hello \0
```

Copy characters:

```text
Copy W → Hello W
Copy o → Hello Wo
Copy r → Hello Wor
Copy l → Hello Worl
Copy d → Hello World
```

Finally:

```text
Add '\0'
```

Memory becomes:

```text
┌───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬────┐
│ H │ e │ l │ l │ o │   │ W │ o │ r │ l │ d │ \0 │
└───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴────┘
```

### Conceptual Implementation

```cpp
void myStrcat(char destination[], char source[])
{
    int i = 0;
    int j = 0;

    while (destination[i] != '\0')
    {
        i++;
    }

    while (source[j] != '\0')
    {
        destination[i] = source[j];
        i++;
        j++;
    }

    destination[i] = '\0';
}
```

### Backend Process

```text
DESTINATION = "Hello "
SOURCE      = "World"

          │
          ▼

Find '\0' in destination

          │
          ▼

Copy source characters

          │
          ▼

Add '\0'

          │
          ▼

"Hello World"
```

### Important

The destination array must have enough space for both strings and the final `'\0'`.

## 4.4 Comparison

### Concept

Comparison means comparing two strings character by character.

```text
Apple
Apply

A = A
p = p
p = p
l = l
e ≠ y
```

### Function

```cpp
strcmp()
```

---

## `strcmp()` — What Happens Internally?

Suppose:

```cpp
char str1[] = "Apple";
char str2[] = "Apple";
```

When:

```cpp
strcmp(str1, str2);
```

Conceptually:

```text
A vs A → Same
p vs p → Same
p vs p → Same
l vs l → Same
e vs e → Same
\0 vs \0 → Both ended
```

Result:

```text
0
```

### Conceptual Logic

```cpp
int myStrcmp(char str1[], char str2[])
{
    int i = 0;

    while (str1[i] == str2[i])
    {
        if (str1[i] == '\0')
        {
            return 0;
        }

        i++;
    }

    return str1[i] - str2[i];
}
```

### Example: Different Strings

```cpp
char str1[] = "Apple";
char str2[] = "Apply";
```

```text
A vs A → Same
p vs p → Same
p vs p → Same
l vs l → Same
e vs y → DIFFERENT
```

### Basic Result

```text
strcmp(str1, str2)

0  → Strings are equal

< 0 → First string comes before second

> 0 → First string comes after second
```

### Backend Idea

```text
STRING 1              STRING 2

A                      A
│                      │
Compare ───────────────┘
Same → Move forward

...

Different character?
        │
        ▼
Return comparison result
```

## 4.5 Searching

### Concept

Searching means looking for a character or a smaller string inside another string.

Example:

```text
String: "Hello World"

Search for: 'W'

              ↓
        Found at index 6
```

### Common Functions

```cpp
strchr()   // Search for a character
strstr()   // Search for a substring
```

---

## `strchr()` — Searching for a Character

Example:

```cpp
char str[] = "Hello";

strchr(str, 'l');
```

The function traverses the string:

```text
H → Is H equal to l? → No
e → Is e equal to l? → No
l → Is l equal to l? → YES
                    ↓
                  FOUND
```

Conceptually:

```cpp
char* myStrchr(char str[], char target)
{
    int i = 0;

    while (str[i] != '\0')
    {
        if (str[i] == target)
        {
            return &str[i];
        }

        i++;
    }

    return nullptr;
}
```

The real library implementation may differ, but this shows the basic idea.

---

## `strstr()` — Searching for a Substring

Example:

```cpp
char str[] = "Hello World";

strstr(str, "World");
```

Conceptually:

```text
Main String:

H e l l o   W o r l d
            ↑
         Start checking

Substring:

W o r l d
```

The search tries to find a position where all characters of the smaller string match in sequence.

### Backend Idea

```text
Start at first position
       ↓
Does substring match here?
   │
   ├── No → Move one position forward
   │
   └── Yes → Return found position
```

## 4.6 Modification

### Concept

Modification means changing characters already stored inside a string.

Example:

```text
Before:

Hello

Change H → J

After:

Jello
```

Because a C-style string is a character array, characters can be accessed by index.

```cpp
char str[] = "Hello";

str[0] = 'J';
```

Internally:

```text
Before:

Index:    0   1   2   3   4   5
Value:    H   e   l   l   o  \0

Change index 0

After:

Index:    0   1   2   3   4   5
Value:    J   e   l   l   o  \0
```

### Backend Idea

```text
String
   ↓
Choose an index
   ↓
Access that memory position
   ↓
Replace character
```

## 4.7 Reversing

### Concept

Reversing means changing the order of characters.

```text
Hello

  ↓

olleH
```

### Backend Idea

The first character is swapped with the last character.

Then the second character is swapped with the second-last character.

```text
H e l l o

↓       ↓
o e l l H

  ↓   ↓
o l l e H
```

Conceptually:

```cpp
void reverseString(char str[])
{
    int left = 0;
    int right = strlen(str) - 1;

    while (left < right)
    {
        char temp = str[left];
        str[left] = str[right];
        str[right] = temp;

        left++;
        right--;
    }
}
```

### Backend Process

```text
Find length
    ↓
left = first index
right = last character
    ↓
Swap
    ↓
Move inward
    ↓
Repeat until pointers meet
```

## 4.8 Case Conversion

### Concept

Case conversion means changing characters from:

```text
hello → HELLO

HELLO → hello
```

This requires traversing the string.

```text
H
↓
Check character
↓
Convert if required
↓
Move to next character
```

Example:

```cpp
#include <cctype>

for (int i = 0; str[i] != '\0'; i++)
{
    str[i] = toupper(str[i]);
}
```

### Backend Idea

```text
Start
  ↓
Read one character
  ↓
Is it the type we want to convert?
  │
  ├── Yes → Replace with converted character
  │
  └── No → Keep it unchanged
  ↓
Move forward
  ↓
Stop at '\0'
```

## 4.9 Tokenization

### Concept

Tokenization means breaking one string into smaller pieces called **tokens**.

Example:

```text
Apple,Banana,Mango
```

Using a comma as a separator (The commas , are the separators, also called delimiters.) :

```text
Apple
Banana
Mango
```

A commonly used C-style function is:

```cpp
strtok()
```

Example:

```cpp
char str[] = "Apple,Banana,Mango";

char* token = strtok(str, ",");

while (token != nullptr)
{
    cout << token << endl;
    token = strtok(nullptr, ",");
}
```

### Conceptual Backend Idea

```text
Apple,Banana,Mango
      ↑
   Separator

Find separator
      ↓
Replace separator internally as needed
      ↓
Return first token
      ↓
Continue searching
      ↓
Return next token
```

**Important:** `strtok()` modifies the original character array.

Example:



## Final Understanding

C-style string functions may have optimized library implementations, but the basic logic behind most operations is:

```text
Start from the beginning
        ↓
Read characters one by one
        ↓
Perform the required operation
        ↓
Find '\0'
        ↓
STOP
```

Once you understand **character arrays, `'\0'`, and traversal**, the rest of C-style string operations become much easier to understand.
