## Short Overview

`std::string` is C++'s standard class for storing and manipulating **text**.

It solves many limitations of traditional C-style character arrays by providing:

- Automatic memory management
- Dynamic resizing
- Built-in text operations
- Safer and more convenient syntax

The topics in this chapter are operations performed on a `std::string`.

---

# 1. String Declaration

To use `std::string`:

```cpp
#include <string>
```

Declaration:

```cpp
string name;
```

Or, more explicitly:

```cpp
std::string name;
```

This creates a **string object**, initially containing an empty string.

```cpp
string name;

cout << name.length();  // 0
```

Unlike a fixed character array, a `std::string` can grow or shrink automatically.

# 2. String Initialization

### Direct initialization

```cpp
string name = "Yanshika";
```

### Empty string

```cpp
string name;
```

### Constructor-style initialization

```cpp
string name("Yanshika");
```

### Repeated characters

```cpp
string stars(5, '*');
```

Output:

```text
*****
```

## Internal idea

Conceptually, a `std::string` manages:

1. A sequence of characters
2. The current number of characters
3. The memory allocated to store them

For example:

```cpp
string text = "Hello";
```

Conceptually:

```text
Characters:  H  e  l  l  o
Index:       0  1  2  3  4

Size: 5
```

The exact internal implementation is not fixed by the C++ standard, but a string generally manages dynamically sized character data.

# 3. String Concatenation

**Concatenation** means joining strings together.

```cpp
string first = "Hello";
string second = " World";

string result = first + second;
```

Output:

```text
Hello World
```

You can also use `+=`.

```cpp
string text = "Hello";

text += " World";
```

Now:

```text
Hello World
```

## `+` vs `+=`

```cpp
a + b
```

usually produces a new combined result.

```cpp
a += b
```

modifies the existing string.

Example:

```cpp
string a = "Hello";
string b = " World";

a += b;
```

The object `a` changes.

## Performance insight

Repeated concatenation can cause memory reallocations.

```cpp
string result;

for (...)
{
    result += something;
}
```

As the string grows, it may need more memory.

When the approximate final size is known:

```cpp
result.reserve(1000);
```

This can reduce repeated reallocations.

# 4. String Comparison

Strings can be compared using comparison operators.

```cpp
string a = "Apple";
string b = "Banana";
```

## Equality

```cpp
a == b
```

Checks whether both strings contain exactly the same characters.

```cpp
if (a == b)
{
    cout << "Same";
}
```

## Lexicographical comparison

```cpp
a < b
```

Strings are compared **lexicographically**, similar to dictionary ordering.

```cpp
"Apple" < "Banana"
```

because `'A'` comes before `'B'`.

Comparison happens character by character.

Example:

```text
"Cat"
"Car"

C == C
a == a
t > r
```

Therefore:

```cpp
"Cat" > "Car"
```

### Important

String comparison is **case-sensitive**.

```cpp
"Apple" != "apple"
```

because:

```text
'A' != 'a'
```

# 5. String Length

Find the number of characters using:

```cpp
string text = "Hello";

cout << text.length();
```

Output:

```text
5
```

You can also use:

```cpp
text.size();
```

For `std::string`, `size()` and `length()` effectively provide the same result.

```cpp
text.size();
text.length();
```

## Why are there two?

- `size()` fits the general container interface.
- `length()` makes semantic sense for text.

`size()` is consistent with other STL containers.

# 6. Character Access

Every character has an index.

```cpp
string text = "Hello";
```

```text
Index:       0   1   2   3   4
Character:   H   e   l   l   o
```

## `operator[]`

```cpp
cout << text[0];
```

Output:

```text
H
```

You can also modify a character:

```cpp
text[0] = 'Y';
```

Now:

```text
Yello
```

### Danger

Accessing outside the valid range is undefined behavior.

```cpp
string text = "Hello";

text[100];  // Dangerous
```

## `.at()`

A safer alternative:

```cpp
text.at(0);
```

If the position is invalid, `.at()` performs bounds checking and throws an exception.

```cpp
text.at(100);
```

This can throw:

```text
std::out_of_range
```

| Feature | `[]` | `.at()` |
|---|---|---|
| Bounds checking | No | Yes |
| Invalid index | Undefined behavior | Exception |
| Common use | Direct access | Safer access |

# 7. `substr()`

`substr()` extracts part of a string.

Syntax:

```cpp
string.substr(start, length)
```

Example:

```cpp
string text = "Hello World";

string result = text.substr(6, 5);

cout << result;
```

Output:

```text
World
```

## How it works

```text
Hello World
01234567890
      ↑
      6
```

```cpp
text.substr(6, 5);
```

Means:

- Start at index `6`
- Extract `5` characters

### Without the length

```cpp
text.substr(6);
```

This means:

> Start at position `6` and continue until the end.

### Important

`substr()` creates and returns a **new string**.

The original remains unchanged.

```cpp
string text = "Hello World";

string part = text.substr(0, 5);
```

```text
text → Hello World
part → Hello
```

# 8. `find()`

`find()` searches for a character or substring.

```cpp
string text = "Hello World";

size_t position = text.find("World");
```

Result:

```text
6
```

because `"World"` starts at index `6`.

## Character search

```cpp
text.find('o');
```

The first `'o'` occurs at index `4`.

## When not found

```cpp
text.find("XYZ");
```

returns:

```cpp
string::npos
```

`npos` means:

> No valid position was found.

Correct usage:

```cpp
if (text.find("World") != string::npos)
{
    cout << "Found";
}
```

### Important trap

Do not assume the result is `-1`.

`find()` returns a position type, commonly:

```cpp
size_t
```

Use:

```cpp
string::npos
```

for comparison.

# 9. `replace()`

`replace()` replaces part of a string.

```cpp
string text = "Hello World";

text.replace(6, 5, "C++");
```

Result:

```text
Hello C++
```

## Syntax

```cpp
text.replace(start, length, replacement);
```

For:

```cpp
text.replace(6, 5, "C++");
```

It means:

1. Start at index `6`
2. Remove `5` characters
3. Insert `"C++"` there

Before:

```text
Hello World
      ↑----↑
      World
```

After:

```text
Hello C++
```

The replacement text does **not** need to have the same length.

The string automatically adjusts its size.

---

# 10. `insert()`

`insert()` adds characters without removing existing characters.

```cpp
string text = "Hello";

text.insert(5, " World");
```

Result:

```text
Hello World
```

Conceptually:

```text
H e l l o | W o r l d
          ↑
```

The implementation may need to move existing characters internally to create space.

# 11. `erase()`

`erase()` removes characters.

```cpp
string text = "Hello World";

text.erase(5, 6);
```

Result:

```text
Hello
```

Syntax:

```cpp
erase(start, length)
```

Here:

```cpp
text.erase(5, 6);
```

means:

- Start at index `5`
- Remove `6` characters

Those characters are:

```text
 World
```

including the space.

## Erasing from a position to the end

```cpp
text.erase(5);
```

This removes everything from index `5` to the end.

# 12. `push_back()`

Adds one character to the end.

```cpp
string text = "Hello";

text.push_back('!');
```

Result:

```text
Hello!
```

A string can be treated as a sequence of characters, and adding to the end is a common operation.

# 13. `pop_back()`

Removes the last character.

```cpp
string text = "Hello!";

text.pop_back();
```

Result:

```text
Hello
```

## Important danger

Calling `pop_back()` on an empty string is undefined behavior.

```cpp
string text;

text.pop_back();  // Undefined behavior
```

Check first when necessary:

```cpp
if (!text.empty())
{
    text.pop_back();
}
```

# 14. String Traversal

**Traversal** means visiting characters one by one.

## Method 1: Index-based traversal

```cpp
string text = "Hello";

for (size_t i = 0; i < text.length(); i++)
{
    cout << text[i] << endl;
}
```

Execution:

```text
i = 0 → H
i = 1 → e
i = 2 → l
i = 3 → l
i = 4 → o
```

## Why `size_t`?

Functions such as:

```cpp
text.size();
```

return an unsigned size type, commonly `size_t`.

Therefore:

```cpp
size_t i = 0;
```

avoids signed/unsigned comparison issues.

## Method 2: Range-based `for` loop

Modern C++:

```cpp
for (char ch : text)
{
    cout << ch << endl;
}
```

This is clearer when you only need the characters.

## Modifying characters

This does **not** modify the original string:

```cpp
for (char ch : text)
{
    ch = toupper(ch);
}
```

Why?

Because `ch` is a **copy** of each character.

Use a reference:

```cpp
for (char& ch : text)
{
    ch = toupper(ch);
}
```

Now the actual characters inside the string are modified.

### Important connection

```cpp
char ch
```

→ copy

```cpp
char& ch
```

→ reference to the actual character

# 15. `getline()`

Normally:

```cpp
cin >> text;
```

reads only until whitespace.

Example input:

```text
Yanshika Singh
```

stores only:

```text
Yanshika
```

## `getline()`

To read an entire line:

```cpp
getline(cin, text);
```

Input:

```text
Yanshika Singh
```

Stored:

```text
Yanshika Singh
```

## How it works

`getline()` keeps reading characters until it encounters a delimiter.

By default, the delimiter is a newline.

```cpp
getline(cin, text);
```

Conceptually:

> Keep reading characters until the user presses Enter.

The newline is consumed but is not stored in the string.

## Custom delimiter

You can specify a delimiter.

```cpp
getline(cin, text, ',');
```

Input:

```text
Apple,Banana,Mango
```

The first call reads:

```text
Apple
```

because it stops at:

```text
,
```

This is useful when parsing structured text.

---

# Important: `cin` and `getline()` Problem

Consider:

```cpp
int age;
string name;

cin >> age;
getline(cin, name);
```

After entering:

```text
20
```

`getline()` may immediately read an empty line.

## Why?

When:

```cpp
cin >> age;
```

reads:

```text
20
```

it stops before the newline.

Conceptually, the input buffer still contains:

```text
\n
```

Then:

```cpp
getline(cin, name);
```

sees that newline immediately and considers the line finished.

## Simple solution

```cpp
cin.ignore();
```

Example:

```cpp
int age;
string name;

cin >> age;
cin.ignore();

getline(cin, name);
```

## More robust solution

```cpp
#include <limits>

cin.ignore(numeric_limits<streamsize>::max(), '\n');
```

This removes remaining characters up to and including the newline.

---

# Practical Example

```cpp
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string text;

    cout << "Enter a sentence: ";
    getline(cin, text);

    cout << "\nOriginal: " << text;

    cout << "\nLength: " << text.length();

    if (text.find("C++") != string::npos)
    {
        cout << "\nC++ was found.";
    }

    text += "!";

    cout << "\nAfter concatenation: " << text;

    return 0;
}
```

This demonstrates that a string is not just text storage—it provides operations to search, modify, compare, and traverse text.

# Traditional vs Modern C++

## C-style string

```cpp
char name[20] = "Yanshika";
```

## Modern C++ string

```cpp
string name = "Yanshika";
```

| Aspect | C-style string | `std::string` |
|---|---|---|
| Size | Usually fixed manually | Dynamic |
| Memory management | Manual awareness required | Managed automatically |
| Length | `strlen()` | `.size()` / `.length()` |
| Concatenation | `strcat()` | `+`, `+=` |
| Comparison | `strcmp()` | `==`, `<`, `>` |
| Safety | Easier to misuse | Generally safer |
| Convenience | Lower | Higher |

## Professional point

`std::string` is generally preferred for normal C++ text handling.

C-style strings still matter when working with:

- Legacy C APIs
- Operating-system APIs
- Low-level interfaces
- Certain embedded systems

# Advanced Insight: `std::string` Is an Object

```cpp
string text = "Hello";
```

`text` is **not simply an array of characters**.

It is an object that manages character data.

Conceptually, it contains information related to:

```text
Character storage
Current size
Memory capacity
```

For example:

```cpp
text.size();
```

does not generally need to count every character from the beginning each time.

A string implementation typically tracks its current size.

---

# `size()` vs `capacity()`

Consider:

```cpp
string text = "Hello";
```

```cpp
text.size();
```

means:

> How many characters are currently part of the string?

Result:

```text
5
```

But:

```cpp
text.capacity();
```

means approximately:

> How much character storage is currently available before more memory may need to be allocated?

Conceptually:

```text
Size:      5
Capacity:  15
```

There may already be room for additional characters.

## Why capacity exists

Suppose a string grows repeatedly:

```cpp
text += 'A';
text += 'B';
text += 'C';
```

If memory were allocated exactly for every new character, the program could repeatedly allocate new memory and copy existing data.

Implementations often allocate extra capacity to reduce repeated allocations and copying.

---

# Performance and `reserve()`

Consider:

```cpp
string result;

for (int i = 0; i < 100000; i++)
{
    result += "Hello";
}
```

The string may grow and reallocate multiple times.

When the approximate final size is known:

```cpp
string result;

result.reserve(500000);

for (int i = 0; i < 100000; i++)
{
    result += "Hello";
}
```

`reserve()` requests sufficient capacity in advance.

This can reduce:

- Memory allocations
- Character copying
- Reallocations

## Important

Do not optimize unnecessarily.

For ordinary small strings, the difference may not matter.

Professional optimization means:

> Understand the cost first, then optimize when the cost is significant.

# Common Mistakes and Dangerous Situations

## 1. Accessing an invalid index

Wrong:

```cpp
string text = "Hello";

cout << text[100];
```

This is undefined behavior.

Correct approach:

```cpp
if (index < text.size())
{
    cout << text[index];
}
```

---

## 2. Forgetting that `find()` can fail

Wrong:

```cpp
size_t pos = text.find("ABC");

text.erase(pos);
```

If `"ABC"` is not found:

```cpp
pos == string::npos
```

Correct:

```cpp
size_t pos = text.find("ABC");

if (pos != string::npos)
{
    text.erase(pos);
}
```

---

## 3. `getline()` after `cin`

Problem:

```cpp
cin >> age;
getline(cin, name);
```

Solution:

```cpp
cin.ignore();
getline(cin, name);
```

For more robust input handling:

```cpp
cin.ignore(numeric_limits<streamsize>::max(), '\n');
```

---

## 4. Modifying copies during traversal

Wrong:

```cpp
for (char ch : text)
{
    ch = 'X';
}
```

The original string does not change.

Correct:

```cpp
for (char& ch : text)
{
    ch = 'X';
}
```

---

## 5. Assuming string comparison means length comparison

```cpp
"Zoo" > "Apple"
```

This is not about which string is longer.

String comparison is **lexicographical**.

Characters are compared in order.

# Key Takeaways

- `std::string` is the standard modern C++ class for handling text.
- It manages dynamically sized character sequences.
- `+` and `+=` concatenate strings.
- `==`, `<`, and `>` compare strings lexicographically.
- `.size()` and `.length()` give the number of characters.
- `[]` provides unchecked access; `.at()` performs bounds checking.
- `substr()` extracts part of a string.
- `find()` searches and returns a position or `string::npos`.
- `replace()`, `insert()`, and `erase()` modify the contents.
- `push_back()` adds one character.
- `pop_back()` removes the last character.
- Range-based loops can traverse strings cleanly.
- Use `char&` when traversal must modify the original characters.
- `getline()` reads complete lines, including spaces.
- Be careful when mixing `cin >>` with `getline()`.
- `capacity()` represents allocated storage capability, while `size()` represents current characters.
- `reserve()` can improve performance when building large strings.

---

# Mental Model

> **Think of `std::string` as a smart, dynamically managed container of characters. It stores text while handling resizing and memory management for you, and provides operations to search, modify, compare, and traverse that text.**

Unlike a simple character array, a `std::string` is an **object that manages text data**.

---

# Common Traps to Remember

- `text[index]` does not automatically protect you from invalid indexes.
- `find()` returning `string::npos` means **not found**.
- `getline()` can read an empty line after `cin >>` because of a leftover newline.
- `for (char ch : text)` gives copies.
- Use `for (char& ch : text)` to modify original characters.
- `pop_back()` must not be called on an empty string.
- String comparison is lexicographical and case-sensitive.
- `substr()` returns a new string; it does not modify the original.
- Repeated string growth can cause reallocations.

---

# When to Use / Avoid It

## Use `+` or `+=` when:

- Combining a small number of strings
- Writing readable code

## Consider `reserve()` when:

- Building a very large string incrementally
- You know the approximate final size

## Use `[]` when:

- The index is guaranteed valid
- You need direct access

## Use `.at()` when:

- Index validity is uncertain
- You want bounds checking

## Use `getline()` when:

- Input can contain spaces
- Reading complete lines
- Parsing text records

## Use `cin >> variable` when:

- You only need a single whitespace-separated value
